## 验收范围

应用的 AMD64 Docker 构建、HTTP 业务、媒体返回和持久化已经实际执行。ARM64 与 Mac 物理设备上的本候选版本没有在本机验收；前一批镜像的 ARM64 记录不替代本批测试。

后端 5 项跳过包括 Windows 独占文件锁和 DPAPI 合同，以及公开包没有附带的两项维护者私有素材/生成记录。它们没有被模拟成通过。分段结果按最终测试 ID 合并；旧的单一重试测试已由 Context / 普通服务两个参数化案例替代。

原生安装工具、四步 LoRA 及内存监管有 CPU 边界回归测试；新便携监管器尚未独立完成一次真实 GPU 生成。原 Windows 工作站的既有 H3 及四步成果不能计为新监管器出片通过。首次部署必须按 [本地节点教程](local-inference.md) 做短镜头生成、完整解码和人工画面审核。

当前精确 H3 / NVFP4 / SMD 路线使用 NVIDIA CUDA，支持基线为 Windows。Linux 原生推理保留为未验收并阻止启动；Mac 运行 Docker 应用并连接用户自己的 Windows NVIDIA 节点。其他云端、普通 ComfyUI 与语言服务沿用各自已实现的适配器，不能把任意 API 当成相同协议。

本次操作使用独立目录、数据库、素材与数据卷。原项目数据库、历史任务、素材、模型、正在运行的服务均未删除或重置。
