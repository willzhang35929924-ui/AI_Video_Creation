# 对白超长处理

当前导航顺序为：项目工作台、剧本生成、脚本与分镜、成片审核、合成成片、系统设置。

在项目工作台找到“需要处理的异常”。当“对白混音”报“对白音频超过原片长度”时，卡片会读取原片和配音文件的实际时长，并提供以下处理。

| 选择 | 操作 | 程序重新处理的范围 |
| --- | --- | --- |
| 延长镜头 | 填入足以容纳全部配音的新时长，核对预览后确认 | 本镜真实视频生成 → 混音 → 原配置的画质处理 → 技术检查；沿用已完成的配音 |
| 缩短台词 | 选具体台词，填写精简后的配音文字；有语言选项时核对语言 | 所选一句配音 → 混音 → 画质处理 → 技术检查；沿用原视频 |
| 调整语速 | 选具体台词，在当前适配器支持范围内设置速度；核对语言 | 所选一句配音 → 混音 → 画质处理 → 技术检查；沿用原视频 |

1. 核对卡片显示的实际视频时长、配音时长、原剧本台词和本轮配音台词。
2. 选择一种处理方式并填写参数，点击“预览处理影响”。此时尚未派发生成。
3. 核对受影响节点，点击“确认并开始重新处理”。后续由程序的现有任务编排自动执行，可在自动制作状态中查看真实结果。
4. 完成后到“成片审核”播放并审核新版本，再到“合成成片”选择已批准版本导出。

缩短台词只修改本轮所选句子的配音文字，原 Word 和剧本文字保留。若以后新建制作也要使用短台词，请同步修改剧本或 Word。英文台词使用 IndexTTS 2.5 时可明确选择 EN；界面会显示原先实际使用的语言，不会自动改写语言。

语速与实际时长并非严格比例。若新音频仍超长，程序会再次显示这三个选择，并使用新音频的实际时长重新计算；不会静默截断音频。超过适配器允许范围的参数会明确拒绝。

每次处理保留原视频、原配音、旧任务和变更记录。新结果需要重新审核，原先批准的旧片不会遮住本次新结果。同镜任务正在运行或提交结果未知时，不会重复派发；请先等原任务结束或核对供应商原请求。

旧“审片与成片”“视频制作”页面入口及其专用后端接口已移除。旧网页收藏分别跳转“成片审核”“脚本与分镜”，共用的自动制作、视频修订与时间线合成继续使用原业务服务。
